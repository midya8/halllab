What this does not claim
One finite all-different relation, not a shared solution for several constraints. Classic Régin theory, not a new algorithm. The native generator uses augmenting matching + Tarjan; its separate checker uses exhaustive partial tuples + Floyd reachability. The browser independently enumerates assignments and uses BFS graph classes.
No production incrementality, scale benchmark, learned model, domain-specific deployment or whole-CSP guarantee. Report verification checks this bounded implementation, not a machine-checked proof of the theorem.
