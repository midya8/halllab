Classic constraint programming, not a new AI algorithm. Native augmenting paths and bitmask counting are checked against independent exhaustive tuples; JavaScript separately enumerates assignments. This tiny reference is not Régin's optimized SCC propagator, a scalability benchmark or a complete multi-constraint solver. Local consistency of several constraints does not imply a shared solution.
